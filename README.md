# Diya's Birthday Interactive Web Experience 🎂✨

A modern, mobile-first birthday web application crafted with sleek dark neon accents, frosted glassmorphism, clean modern typography, and touch interactions.

Ready for 1-click deployment on **GitHub Pages**, **Netlify**, or **Vercel**!

---

## 📱 Page Flow & Core Features

1. **Interactive Envelope & Scroll-Lock Hero Reveal**:
   - The screen is scroll-locked on launch so she must tap the glowing heart seal to open the letter.
   - On tap: Flap flips open, the envelope zooms in and smoothly fades out while celebratory confetti cannons fire.
   - Diya's portrait smoothly zooms into view, unlocking page scrolling with a sleek bouncing navigation cue.

2. **Stackable 3-Page Letter ("A Letter You Can Feel")**:
   - Physical layered card stack with 3 heartfelt, touching letters.
   - Genuine, moving text celebrating your friendship, what makes her rare, and birthday promises.
   - Interactive touch swipe gestures: swiping left, right, or tapping cycles through pages with real-time card tilt physics and progress dots.

3. **Memory Board (Masonry Scrapbook + Smooth Fullscreen Lightbox)**:
   - Clean sans-serif typography with scrapbook captions.
   - Contains 14 childhood photos (`child1.jpg` to `child14.jpg`) and 7 looping video memories (`video1.mp4` to `video7.mp4`).
   - Clicking/tapping any photo or video opens a smooth fullscreen lightbox with backdrop blur. Tapping anywhere on the empty space closes it back down.

4. **Navratri Bump (Photo Deck 1–9, Pure Touch Swipe, No Buttons)**:
   - Replaces the generic card carousel with a stacked photo deck of her 9 Navratri looks (`nav1.jpg` to `nav9.jpg`).
   - Clean, professional swipe-only interaction: swiping across the screen tosses the top card away and reveals the next look.
   - Progress tracking pill: "Look X of 9".

5. **Our Soundtrack ("Mara Tame Su Thav Cho" / Ramo Re)**:
   - Dedicated MacBook player displaying the Navratri anthem: *Mara Tame Su Thav Cho ( Diya's fav one )*.
   - Plays `assets/Ramo-Re.mp4` automatically and starts muted for instant mobile autoplay compliance.
   - Unobtrusive sound toggle button to unmute and hear the music at any moment.

6. **Interactive Gold Scratch Card**:
   - Metallic gold scratch-off canvas layer. Rubbing reveals the secret "Lifetime Bestie Voucher" with automatic completion and confetti bursts once over 50% is scratched.

7. **Grand Birthday Finale**:
   - Birthday cake animation, celebratory best wishes, multi-burst confetti launcher, and a "Back to Top" restart button.

## 🚀 How to Host on GitHub Pages (Free)

1. Create a repository on GitHub (e.g., `for-diya`).
2. Upload the project files:
   - `index.html`
   - `style.css`
   - `script.js`
   - `assets/` folder
3. Go to **Settings** > **Pages**.
4. Set source branch to `main` and root `/`, then save.
5. Share the generated link with Diya!
